# Mode ∞ · The Builder

At any level of participation, OGs may build onto the Realm's existing framework — programs, apps, bots, and side market economies. This is the open-ended mode: its ceiling is your own.

## The License

> *If the code allows for it, it is legal in the Realm of OGs.*

That is the whole license. No permission, no application, no registry. The Realm's contracts, pools, and data are public; what you can build against them, you may.

## What Builders Build

* **Tools** — trackers, dashboards, alert bots; the Realm's state is public and machine-readable through the [Agent's Gate](../canon/agents-gate.md)
* **Automation** — epoch-disciplined mining, allocation strategies, claim reminders; the games reward consistency that code performs perfectly
* **Markets** — new pools, new pairs, side economies on Realm tokens; the [Regulated Pools](../physics/liquidity-pools.md) are a floor, not a fence
* **Agents** — the Realm is AI-compatible by construction; an agent that reads the docs reads the same truth a human does

## Why the Realm Wants You

Every tool deepens the Realm's surface; every side market is new flow across its pools; every agent is a tireless new player. Builders have already shipped bots, dashboards, and infrastructure the community now leans on — and building is itself visible history on the chain, the kind the Realm [judges kindly](../era-2/alchemy-airdrop.md).
